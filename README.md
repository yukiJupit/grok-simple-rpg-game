# 勇者のお前 ～魔王城への道～

**Grok AIとGitHub Connectorsで作成した簡単テキストベースRPGゲーム**

ターン制バトルで敵を倒し、経験値を短めてレベルアップ！
スライム、ゴブリン、ドラゴンと戦う王道RPGです。

## プレイ方法

```bash
python rpg_game.py
```

1. Pythonがインストールされている環境で上記コマンドを実行
2. 勇者の名前を入力
3. 1を選択して戦闘開始！

## ゲームの特徴
- ターン制バトル
- 攻撃・防御・魔法の選択
- ランダム敵出現
- レベルアップシステム
- 日本語でプレイ可能
